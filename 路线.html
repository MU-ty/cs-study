A PRACTICAL ROADMAP

先建立基础，
再连接成体系。

路线不是必须照搬的课表。每个阶段都有“完成标准”，达到标准再往后走，比仅仅看完课程更重要。

01

编程基础

用一门语言熟悉变量、分支、循环、函数和调试，形成“把问题拆成步骤”的能力。

  • 主线：C / C++ 或 JavaScript 任选其一
  • 工具：终端、编辑器、Git 基本操作
  • 实践：独立完成 3 个小程序
完成标准能从报错信息定位问题，能写函数拆分任务。学习 JavaScript
02

数据结构与算法

理解结构如何影响操作效率，训练边界意识和复杂度分析，而不是只背模板。

  • 线性：数组、链表、栈、队列、哈希表
  • 非线性：树、堆、图、并查集
  • 算法：二分、搜索、贪心、动态规划、最短路
完成标准能解释时间复杂度，能独立写出 BFS、DFS 和二分。进入 10 个可视化实验进阶：并查集、贪心、动态规划与最短路可按清单继续学习。
03

计算机网络

沿一次请求的完整路径理解分层、寻址、路由、可靠传输和应用协议。

  • 基础：分层、物理层、链路层、IP 与子网
  • 核心：路由、TCP / UDP、DNS、HTTP / TLS
  • 实践：ping、traceroute、curl、Wireshark
完成标准能从输入网址讲到页面返回，并按层排查连接故障。进入 18 章实验
04

操作系统与数据库

理解程序运行时的资源管理，再学习数据如何持久保存、查询和保证一致性。

  • 操作系统：进程线程、虚拟内存、文件与 I/O
  • 数据库：SQL、索引、事务、锁与 MVCC
  • 实践：Linux 命令、MySQL 执行计划
完成标准能解释一次查询的执行路径，能定位常见性能问题。课程正在整理，当前可按清单自学。
05

软件工程与项目

把分散知识放进真实项目：定义需求、设计接口、测试、部署、观测和迭代。

  • 工程：Git 分支、代码规范、测试、CI/CD
  • 后端：API、缓存、消息、权限与日志
  • 作品：能运行、能说明取舍、能复盘问题
完成标准独立交付一个可访问项目，并写清架构、难点和验证方式。查看项目仓库
