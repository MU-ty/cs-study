CSS 不是“调颜色”，
而是描述页面的视觉规则。

从“选中谁”开始，理解元素占多大空间、如何排列，以及屏幕变化时该怎样响应。每一节只解决一个核心问题。

内容内边距边框外边距
01

SELECTORS

先回答：这条样式作用于谁？

选择器把样式规则连接到元素。优先用类表达可复用样式，用 ID 标识页面中唯一目标；组合选择器描述结构关系。

p { color: #445; }          /* 标签 */
.card { border-radius: 12px; } /* 类 */
#hero { min-height: 60vh; }    /* ID */
.card > h2 { margin: 0; }      /* 直接子元素 */
优先级相同时，后出现的规则覆盖前面的规则；优先级更高的选择器不受书写先后影响。
02

BOX MODEL

页面里的每个元素，都是一个盒子

margin
border
padding
content
240 × 80

box-sizing: border-box 让声明的宽高包含 padding 和 border，布局计算更直观。外边距负责盒子之间的距离，内边距负责内容到边框的距离。

03

FLEXBOX

一维排列：一行或一列

.row {
  display: flex;
  justify-content: space-between; /* 主轴 */
  align-items: center;            /* 交叉轴 */
  gap: 16px;
}
Logo课程路线

Flex 适合导航、工具栏、卡片内部等一维关系。flex-wrap: wrap 可以在空间不足时换行。

04

GRID

二维排列：同时控制行和列

.cards {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 20px;
}
ABCDEF

Grid 更适合页面区块和卡片矩阵。minmax(0, 1fr) 能避免内容撑破等分列。

05

RESPONSIVE

不是把桌面页面缩小，而是重新安排信息

@media (max-width: 720px) {
  .cards { grid-template-columns: 1fr; }
  .nav { display: none; }
}

优先使用弹性尺寸：%、rem、fr、min() 和 clamp()。媒体查询只处理真正需要变化的断点。

在手机上检查：是否横向溢出？按钮是否容易点击？文字放大到 200% 后是否仍可读？
06

CUSTOM PROPERTIES

把重复的视觉决定变成设计变量

:root {
  --brand: #167d77;
  --space: 16px;
  --radius: 12px;
}
.button {
  background: var(--brand);
  padding: var(--space);
  border-radius: var(--radius);
}

变量让颜色、间距和圆角保持一致。修改一个值即可更新整个界面，也能在局部容器中覆盖变量形成主题。
