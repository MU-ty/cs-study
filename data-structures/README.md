# 数据结构可视化实验室

纯 HTML / CSS / JavaScript，部署到 GitHub Pages，无构建与第三方脚本依赖。

10 个教学模块：数组、单链表、栈、队列、哈希表、二叉搜索树、大顶堆、BFS / DFS、冒泡 / 插入排序、二分查找。每章含交互轨迹、三张知识卡、自测与本地学习记录。

支持步进、回退、播放暂停、速度选择和进度拖动。算法生成独立快照，不通过倒放修改底层状态。数据允许最多 12 个 -99 到 99 的整数；图使用固定六结点无向图，起点按模 6 规范化。

教学边界：链表是逻辑结点图，不表示实际地址；队列使用数组 shift 展示语义，非 O(1) 实现；哈希表为固定七桶的链地址集合模型，不自动扩容；BST 不平衡且忽略重复键；堆每次从输入重新建堆；二分的预排序成本另计，返回排序后位置。排序帧显示暂存元素，移动时数组中临时重复不是数据丢失。学习记录仅存当前浏览器，无法跨设备同步。

运行测试：`node --test data-structures/engine.test.js`。从仓库根目录启动任意静态服务器即可本地使用。使用 Node 内置测试检查边界、排序结果、堆性质、树与图遍历顺序；不声称测试能替代真实浏览器 QA。
