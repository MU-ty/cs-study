# 操作系统可视化实验室

八个模块：进程状态；FCFS / 非抢占 SJF / RR；生产者消费者；死锁与统一资源顺序；FIFO / LRU；分页地址转换；FCFS / SSTF / LOOK 磁盘调度；连续 / 索引文件分配。

支持自定义输入、步进、回退、自动播放与暂停、速度调整、步骤拖动；每章三张知识卡、一题自测与浏览器本地学习标记。纯静态文件，无第三方脚本、无需构建。样式复用数据结构实验室，保留紫色主题。

## 教学约定

- CPU：单 CPU，仅一个 CPU burst，无 I/O 和上下文切换开销。SJF 非抢占；RR 同刻到达者先入队，再入队未完成的片到期进程。最多六个进程。到达 0–20，burst 1–10，时间片 1–10。
- 同步：单生产者、单消费者，显示完整原子化操作后的稳定状态；等待者被唤醒后完成先前操作。full / empty 表示可用产品/槽数，不模拟具体内核信号量的负值或调度队列。
- 死锁：两种单实例资源；有环判断不可泛化到多实例情况。统一顺序为预防，不是银行家避免算法。
- 页面：固定页框，无脏页、预取、TLB 或真实页表维护成本；FIFO 命中不改变置换队列，LRU 用访问序号维护精确最近使用。
- 地址：四页虚拟空间，固定映射 [2,5,未驻留,1]；合法未驻留页报告缺页，越界报告非法地址，未自动模拟缺页装入。
- 磁盘：请求起始时全到达，忽略旋转与传输；LOOK 初始向较大磁道；SSTF 距离相同保留原输入顺序。此机械磁盘模型不代表 SSD 调度。
- 文件：固定四块文件，只展示映射，非实际 inode、缓存或日志文件系统实现。

## 测试

`node --test os-lab/engine.test.js`

测试检查调度指标、RR 边界入队、信号量稳定状态、FIFO 异常、LRU 缺页、地址边界和磁头移动。额外 DOM 状态模拟不是浏览器视觉验收。内容与交互为独立编写。
